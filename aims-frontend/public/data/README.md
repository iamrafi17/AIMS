The `psgc-addresses.json` file powers the staff profile address selectors.

Source: [bendlikeabamboo/barangay](https://github.com/bendlikeabamboo/barangay), MIT licensed, derived from the Philippine Statistics Authority PSGC masterlist. The JSON records its source version. Regenerate it with `npm run update:psgc-addresses` when the source publishes an update.

The app serves this data locally so address selection does not depend on a third-party API or require an access token.
